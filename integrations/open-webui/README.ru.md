# Интеграция с Open WebUI

[English](README.md) | **Русский**

> **СТАТУС: УСТАРЕЛО с 13.10.2026.** Open WebUI v0.12.0+ использует встроенные **Model Controls** для выбора `reasoning_effort`. Фильтр `siwc_think` больше не нужен и не должен использоваться одновременно со встроенными Model Controls. Файл оставлен для Open WebUI **до v0.12.0**.

Этот каталог содержит необязательный Filter Function для выбора глубины рассуждений Responses API. Адаптер по-прежнему преобразует плоское поле Open WebUI `reasoning_effort` в объект Responses API `reasoning.effort`.

## Установка только для старых версий Open WebUI

1. Откройте **Admin Panel → Functions** и создайте Filter Function.
2. Скопируйте [`functions/siwc_think.py`](functions/siwc_think.py), сохраните и включите для SIWC-моделей.
3. Оставьте переключатель **Think** в поле создания сообщения. В пользовательских настройках Function установите `reasoning_effort`. При включенном Think уровень по умолчанию - `high`.
4. Выключайте Think для поведения Auto/default. Когда Think выключен, фильтр не вмешивается в значение из Advanced Parameters.

В Open WebUI доступны **Chat Controls → Advanced Parameters → Reasoning Effort**. Фильтр не меняет промпты, ID моделей, credentials, посторонние поля, файлы или внешние ресурсы и не выполняет сетевые запросы.

## Поддерживаемые значения моделей

Каталог OpenAI сообщает ID моделей, но не включает детальную информацию о поддерживаемых уровнях reasoning. Поэтому фильтр использует проверенную таблицу точных ID. Неизвестная модель не изменяется. Если известная модель не поддерживает выбранный уровень, выводится ошибка вместо скрытой подмены.

| Модели (по проверке автора от 09.10.2026) | Уровни |
| --- | --- |
| `gpt-5.6-luna`, `gpt-5.6-terra`, `gpt-5.6-sol`, `gpt-6-sol`, `gpt-6-luna` | `none`, `low`, `medium`, `high`, `xhigh`, `max` |
| `gpt-6-astra`, `gpt-6.1-sol` | `low`, `medium`, `high`, `xhigh`, `max` |

`none` не поддерживается GPT-6 Astra и GPT-6.1 Sol. В Open WebUI v0.11.4 пользовательский селектор не умеет динамически менять схему по модели; неподдерживаемые значения отклоняются при использовании.

Перепроверяйте возможности моделей по актуальным страницам OpenAI, когда меняются каталог или контракт API. Не угадывайте возможности по названию и не подменяйте один уровень другим.

## Проверки

`tests/test_open_webui_reasoning_filter.py` проверяет передачу значений, отказ для неподдерживаемых уровней и отсутствие действий для неизвестной модели. Живая приемка с реальным SIWC записана отдельно в приватной эксплуатационной документации; CI не выполняет реальную авторизацию и модельные запросы.
